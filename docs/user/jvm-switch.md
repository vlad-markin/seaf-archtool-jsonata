# Переход инсталляции на JVM-движок

Что меняется, когда в инсталляции SEAF ArchTool включают JVM-движок (флаг CAP-16), и как проверить своё озеро заранее. Как включается сам флаг, описывает документация ядра.

## Что меняется

- **Выражения** вычисляет движок на JVM, а не jsonata-js 2.2.2. Результаты те же, кроме мест со страницы отличий (`differences.md`).
- **Функции манифеста** (`functions`) загружаются при загрузке версии манифеста. Имя, совпадающее со встроенной функцией, — ошибка загрузки `X0014`.
- **Лимиты.** Вычисление ограничено временем (60 с), длиной строки (2²⁶ символов) и размером результата; бесконечная рекурсия заканчивается ошибкой `D1011`. Это временные значения до замеров на озёрах (`docs/limits.md`).
- **Ошибки** имеют код (`T2001`, `X0015`…), позицию и диапазон в выражении, стек вызовов и id функции манифеста. Коды движка — `docs/error-codes.md`.
- **Скорость.** На синтетике движок быстрее jsonata-js в 4–30 раз (`docs/perf-method.md`; приёмочные замеры — на выделенной машине).

## Проверить озеро до включения

`jsonata-tools` не публикуется; его собирают из исходников движка (нужен JDK 21; Gradle скачает его сам, если нет):

```
git clone <репозиторий движка> && cd seaf-archtool-jsonata
./gradlew :jsonata-tools:installDist
jsonata-tools/build/install/jsonata-tools/bin/jsonata-tools detect --lake <путь к озеру> --manifest <выгрузка манифеста.json> --out build/detect
```

Выгрузку манифеста даёт запрос `($)` к порталу. Результат:

- на экране и в `build/detect/summary.json` — сколько выражений может затронуть каждое отличие («может затронуть») и где отличие проявилось при вычислении на вашем манифесте («подтверждено»), конфликты имён функций манифеста, схемы функций, которые упадут при первом вызове, вызовы `$set`/`$get`, покрытие (сколько выражений вычислено и почему остальные — нет);
- в `build/detect/details.json` — места находок. Этот файл содержит данные вашей архитектуры: не публикуйте его.

Выражения, которым нужны `$self` и `$params`, вычисляются, только если для них задан контекст: файл `--contexts contexts.jsonl` со строками `{"place": "<место>", "self": {…}, "params": {…}}`.

Полная проверка против текущего ядра — гейт озёр `jsonata-tools lake-gate` (нужны checkout ядра и запущенный backend; `docs/compat-policy.md`).
