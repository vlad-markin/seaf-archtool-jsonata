## Intent
**Problem:** Свой движок пишется ради скорости на больших архитектурах, но цели не записаны. Порт dashjoin дал 1,2–11× при памяти в 3–5 раз больше V8. Без стенда и целей нельзя ни принять движок, ни оценить предложение отличия «ради производительности» (CAP-1).
**Approach:** Стенд с синтетикой и реальными озёрами, методика и цели CAP-14. Тот же стенд меряет цену отладки (CAP-12) и задержку отмены (CAP-13).

## Boundaries & Constraints
**Always:** результаты движка и jsonata-js сравниваются на каждой паре «запрос × размер»; медиана и p95; аллокации через `ThreadMXBean`; load average в каждой строке; A/B с чередованием для версий движка; оптимизации — под флагами.
**Never:** коммитить данные озёр и тексты выражений корпуса; принимать оптимизацию, меняющую результат, без CAP-1; сравнивать числа с нагруженной машины без пометки.

## I/O & Edge-Case Matrix
| Scenario | Input / State | Expected Output / Behavior | Error Handling |
|----------|--------------|---------------------------|----------------|

| jsonata-js не отработал | Квадратичная сортировка 50 тыс. (падение по памяти) | Пара отмечена «JS не завершился», движок отработал | — |

## Tasks & Acceptance
**Execution:**
- [ ] Генератор данных и набор запросов, раннеры движка и jsonata-js, сравнение результатов (CAP-14 пп. 1–2).
- [ ] Метрики: медиана, p95, аллокации, пик кучи, load average; A/B с чередованием (CAP-14 п. 7).
- [ ] Прогон по реальным озёрам локально, агрегированный отчёт (TC-22).
- [ ] Отчёт о целях CAP-14 пп. 3–6 и порогах CAP-12, задержке отмены CAP-13 (TC-17, TC-18, TC-21); пороги — ориентир, пересмотр с владельцем по итогам первого прогона.
- [ ] Лимиты по умолчанию CAP-13: p99 корпуса на озёрах с запасом, по профилям хоста (портал, DevTool, IDE, сервис); заменяют временные значения `docs/limits.md`.

**Acceptance Criteria:**
- Given стенд 10/50/200 тыс., when движок и jsonata-js 2.2.2 прогоняют 14 запросов, then результаты равны, и на каждой паре движок не медленнее (TC-21).
- Given 200 тыс. компонентов, when замеряется память, then минимальная куча не больше 2× V8 (TC-21).
- Given реальные озёра, when прогоняются выражения корпуса, then ни одно не медленнее jsonata-js, а в репозитории только агрегированная таблица (TC-22).
