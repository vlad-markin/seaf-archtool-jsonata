# Тест-кейсы MAJOR-ERA-0000-jsonata-kotlin

Данные и стенд:
- test-suite jsonata-js 2.2.2 (`compat/jsonata-js/test-suite`, 1686 случаев);
- эталон `jsonata@2.2.2` в `compat/node`;
- корпус SEAF (`compat/corpus`, локально, не меньше 1215 выражений);
- озёра: публичный `seaf-company-example-jupiter` и реальные озёра владельца (локально; конкретные озёра он назовёт при историях 1 и 6);
- синтетический стенд 10/50/200 тыс. компонентов с фиксированным seed;
- корпус дифф-фаззинга не меньше 40 тыс. случаев.

Среды:
- **unit** — модульные и интеграционные тесты `./gradlew build`, без корпуса и озёр;
- **compat** — `./gradlew :jsonata-compat:test` против эталона, с локальным корпусом;
- **lake** — локальный прогон на реальных озёрах против jsonata-js 2.2.2;
- **bench** — стенд производительности, отдельная машина или отмеченная нагрузка;
- **core, ide** — инсталляция инструмента с флагом CAP-16; проверяется в отдельных задачах зон core и ide.

Автотест обязателен для каждого TC, кроме отмеченных «ручной».
