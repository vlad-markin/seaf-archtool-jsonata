# План развития движка (утверждено владельцем 2026-10-25)

Копия утверждённых документов задачи ERA-0000 для облачных сессий. Источник спеки — репозиторий specs (BMAD), здесь — снимок; при расхождении спрашивай владельца.

| Файл | Что |
|---|---|
| `PRD.md` | требования продукта |
| `SPEC.md`, `brownfield.md`, `test-cases.md` | спека: 16 CAP, 29 TC, привязка к коду |
| `stories/1…6` | истории: 1 политика и гейты совместимости, 2 реестр функций и каталог, 3 функции манифеста и ядра SEAF, 4 управление вычислением, 5 отладчик и трассировка, 6 производительность и память |
| `design.md` | дизайн решателя (круг 2): шаги-коммиты по историям, что облако / что локально (§4.0) |
| `decision.md` | решение главного архитектора: обязательные условия У1–У7 и порядок работ (§4) |
| `cloud-task.md` | задание текущей облачной сессии |

Пути вида `roles/…`, `work/…`, `notes/…` в документах — локальные файлы команды, в этом репо их нет; всё нужное для работы — здесь и в `docs/`.
