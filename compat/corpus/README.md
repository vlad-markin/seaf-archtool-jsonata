# Корпус реальных выражений SEAF

Файлы `*.jsonata`, по одному выражению на файл: запросы метамодели SEAF, датасетов, `manifest.functions`.
Корпус собирается **локально** владельцем или локальной сессией: исходники выражений лежат в репозиториях, которых нет в облаке.
Анонимизация обязательна: в выражениях не должно быть имён систем и людей из реальных архитектур.

После пополнения: `cd ../node && node dump-ast.mjs` — снапшоты корпуса пишутся в `../snapshots/ast/_corpus.json`.
Корпус проверяется только на разбор (AST); вычисление на реальных данных — фаза 8.
