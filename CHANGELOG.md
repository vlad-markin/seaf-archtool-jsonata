# Changelog

Версии — semver; до появления `jsonata-host` версии 0.x: несовместимое изменение API или отличие, меняющее результат, поднимает minor (`docs/compat-policy.md`). Отличия от jsonata-js 2.2.2 и ядра — `docs/deviations.md` и `docs/user/differences.md`.

## 0.1.0 — не выпущена

- Движок JSONata на JVM: парсер (AST как у jsonata-js 2.2.2), вычислитель, стандартная библиотека; test-suite 2.2.2: ast 1686/1686, eval 1685/1686 плюс 1 случай DEV-10.
- Отличия DEV-01…DEV-17 (`docs/deviations.md`).
- Реестр функций с определениями, документацией и каталогом; структурированные ошибки с диапазоном и стеком.
- Управление вычислением: отмена, дедлайн, бюджеты шагов, строк и результата, сегментированный стек.
- Отладка: слушатель вычисления, сессия отладки (точки останова, шаги, кадры, вычисление в кадре), профиль и трассировка; консольный отладчик `jsonata-tools debug`.
- Модуль `jsonata-seaf`: функции ядра SEAF (кроме `$wcard`, `$mergedeep`, `$sourcetype`), функции манифеста, JSON Schema через networknt (поведение ajv ядра), детектор SEAF, временные лимиты.
- `jsonata-tools`: детектор отличий по озеру, гейт озёр.
- Стенд производительности `jsonata-bench`.
