# seaf-archtool-jsonata

Движок JSONata для JVM (Kotlin), совместимый с jsonata-js 2.2.2. Артефакты `su.seaf.archtool:jsonata-*`.

- `./gradlew build` — сборка и тесты, отчёт совместимости в `jsonata-compat/build/compat-report.json`.
- Устройство, правила и команды — `CLAUDE.md`; план — `docs/roadmap.md`; решения — `docs/context.md`.
- `compat/jsonata-js/` — вендоринг jsonata-js v2.2.2 под лицензией MIT (см. `compat/jsonata-js/LICENSE`).
